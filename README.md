# wordgarden.me

Static site for Word Garden Daily, served by GitHub Pages at https://wordgarden.nl (wordgarden.me redirects here).

- `index.html` + `assets/<zh|en|nl|es>/`: the promo page (source: `exports/launch-2026-11-18/site/` in the word-garden repo).
- `privacy.html`: the privacy policy (source: `public/privacy.html` in the word-garden repo).
- `open-data.html` + `dictionaries/` + `library/`: word-data downloads (source: `public/` in the word-garden repo; only the files the page links to).
- Update: run `./sync.sh`, then commit and push.
